# CS305-SNHU
## Briefly summarize your client, Artemis Financial, and their software requirements. Who was the client? What issue did they want you to address?
Artemis Financial, to strengthen security in its existing application, entrusted me with a thorough review. I carefully identified vulnerabilities related to outdated libraries and dependencies, using static testing and automation. This proactive approach not only uncovered significant risks but also suggested specific improvements that did not affect the application’s functionality. By enhancing security measures, we protected sensitive client and business information, thereby increasing Artemis Financial's trust and compliance in a competitive environment.
## What did you do particularly well in identifying their software security vulnerabilities? Why is it important to code securely? What value does software security add to a company’s overall wellbeing?
Testing my code for potential vulnerabilities through static analysis was a valuable experience. It highlighted the importance of secure coding in safeguarding both your property and your users' assets. The damage caused by losing personal information and trade secrets can be severe. Writing secure software is not just about protecting sensitive data but also about maintaining a company’s reputation over time.
## What about the process of working through the vulnerability assessment did you find challenging or helpful?
The dependency check tool proved to be the most valuable in the vulnerability assessment process. It significantly reduced the time required to identify vulnerabilities by automatically scanning each dependency for potential issues. This tool was crucial to our proactive security approach, enabling us to identify and resolve vulnerabilities before they could be exploited.
## How did you approach the need to increase layers of security? What techniques or strategies would you use in the future to assess vulnerabilities and determine mitigation techniques?
Most vulnerabilities found during testing stemmed from outdated libraries. Updating these libraries to the latest versions enhances the software's security. In the future, utilizing penetration testing will enhance code evaluation and aid in detecting more vulnerabilities.
## How did you ensure the code and software application were functional and secure? After refactoring code, how did you check to see whether you introduced new vulnerabilities?
Throughout the software development process, I consistently ran debugs to ensure the code was functional and error-free. This proactive approach to quality assurance enabled me to identify and resolve potential issues early, resulting in robust and reliable software. After refactoring the code, I conducted another vulnerability test to ensure no new vulnerabilities were introduced.
## What resources, tools, or coding practices did you employ that you might find helpful in future assignments or tasks?
I frequently used Stack Overflow and looked at how others were solving similar problems to mine, especially when encountering errors in the console.
## Employers sometimes ask for examples of work that you have successfully completed to demonstrate your skills, knowledge, and experience. What from this assignment might you want to showcase to a future employer?
My use of a hash function for encrypted communications highlights my commitment to secure data transmission. I also employed techniques such as digital signatures and symmetric key encryption to ensure the integrity and confidentiality of the information shared within the application. This experience deepened my understanding of encryption and underscored the importance of robust security protocols in safeguarding user data. Presenting this project would showcase my practical skills in secure coding, vulnerability analysis, and proactive mitigation. These abilities are highly valued by employers seeking reliable and security-conscious developers.
